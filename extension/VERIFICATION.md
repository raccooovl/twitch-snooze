## Scope

Public live checks used a fresh signed-out profile. Signed-in Following was covered by Twitch-shaped fixtures and remains unverified on a real account. The executed browser checks used Edge; Chrome uses the same Manifest V3 implementation.

Category filtering depends on category text currently exposed by Twitch. Unknown categories remain visible. Twitch removes category text from its native collapsed sidebar; category rules there need a matching current stream card on the page or an expanded sidebar. Timed snoozes remain available when collapsed. Category changes take effect when Twitch updates the page markup.

The hidden-streamer list includes saved streamer rules plus category matches currently loaded in open Twitch tabs; whitelisted streamers appear in their own tab. It does not enumerate Twitch's entire catalogue. Observations are transient; only numeric tab IDs enter session storage. Rules, chosen exceptions and whitelist entries stay in local extension storage.

No cookies, account data, or settings from the user's browser were used. Testing profiles are disposable.

The extension keeps the six approved presets and requests only storage, alarms, and access to Twitch through its content script. It makes no outbound requests and contains no analytics, external scripts, or server dependency.
